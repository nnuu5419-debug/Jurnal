# Jurnal — Студенттердин катышуусун көзөмөлдөө системасы

## Долбоор жөнүндө
Jurnal — колледждеги студенттердин сабакка катышуусун көзөмөлдөө жана эсепке алуу үчүн иштелип чыккан система.

## Негизги мүмкүнчүлүктөрү
- Жаңы группаларды кошуу.
- Ар бир группага студенттерди каттоо.
- Студенттердин санын көрсөтүү.
- Күн сайын сабакка катышууну белгилөө.
- Студенттердин бар же жок экенин каттоо.
- Бир жумалык катышууну көзөмөлдөө.
- Ар бир группанын катышуу пайызын эсептөө.
- Жумалык отчетторду көрүү.

## Долбоордун максаты
Колледждеги студенттердин сабакка катышуусун автоматташтыруу, окутуучулардын жана администрациянын ишин жеңилдетүү.
